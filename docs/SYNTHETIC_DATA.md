# 합성 데이터와 서비스 정확도 (2026-10-16)

멘토링 피드백("기존 데이터를 기반으로 합성해야 한다 · synthpop · 반반 나눠 검증")을 반영했다.
`data/citizens.json` 30명은 규칙 경계값 검증용으로 유지하고, 현실 분포 시험용 데이터를 따로 만들었다.

## 1. 합성 데이터 — `scripts/synthetic/synth_mdis.py`

- 원자료: 국가데이터처 MDIS 가계금융복지조사 2025 가구마스터(공공용). **저장소에 포함하지 않는다**
  (국가통계 자료제공 규정 제17조: 무단 공유 금지, 활용 후 파기). MDIS 다운로드 서비스에서 직접 받는다.
- 공공용 자료는 시·도 구분이 없어 비수도권(대구 포함) 12,587가구를 쓴다.
- 무작위 반반 분할(A 학습 / B 검증) → A로만 python-synthpop 0.1.2 CART 합성 → 학습 원자료와 똑같은 행 제거 → B와 비교.
- 결과(집계만): `docs/results/synthetic_validation.json`, 그림 `docs/assets/synthetic_rates.png`

| 기준 (가구 경상소득·순자산 근사) | 실제 B | 합성 S |
|---|---|---|
| 중위소득 50% 이하 | 21.1% | 22.3% |
| 연소득 3,500만 이하 | 38.2% | 38.9% |
| 연소득 4,000만 이하 | 43.3% | 43.2% |
| 버팀목 (5천만·순자산 3.45억) | 44.7% | 43.5% |
| 디딤돌 (6천만·순자산 5.11억) | 54.8% | 55.1% |
| 65세 이상 가구주 | 42.7% | 43.8% |

분포 차이 KS ≤ 0.03, 변수 관계(스피어만) 차이 0.021(실제 A·B끼리 0.015), 학습 원자료와 동일한 행 0건(86건 제거), 합성 6,207가구.

## 2. 서비스 정확도 — `scripts/synthetic/service_accuracy.py`

합성 6,207가구를 시민으로 보고 실제 프로토타입 코드(판정 엔진 → VC 발급 → VP → 검증)를 그대로 돌렸다.
원장만 메모리 스텁으로 바꿨다. 정답 = 독립 참조 구현(`packages/rules/py/src/dbp_rules/reference.py`)의 판정.
결과: `docs/results/service_accuracy.json`

| 측정 | 건수 | 결과 |
|---|---|---|
| 판정 일관성 (엔진 = 참조, 가구 × 11항목) | 68,277 | 100% 일치 |
| 자격 있는 항목 정상 제출 | 24,382 | 통과 24,382 · **오거절 0** |
| 자격 없는 항목 위조 증명서 제출 | 43,895 | 차단 43,895 · **오승인 0** |
| 자격 없는 항목 남의 증명서 도용 | 43,895 | 차단 43,895 · **오승인 0** |
| 폐기된 증명서 제출 (발급분 5%) | 1,219 | 차단 1,219 |
| 같은 제출 재전송 | 1,188 | 차단 1,188 |
| 검증 처리 시간 (프로세스 내) | 24,382 | p95 1.54ms |

한계: 정답은 규칙을 실제 값에 적용한 결과다(공식 판정 대조 아님). 거주는 전원 대구로 가정, 수급·학생 자녀·신용은 공공용 자료에 없어 제외, 소득은 가구 경상소득. 처리 시간에 네트워크·체인 지연은 없다(실서버 p95는 `docs/TEST_REPORT.md`).
