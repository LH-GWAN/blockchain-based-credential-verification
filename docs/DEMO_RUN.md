## 미완료·주의
- LLM 키는 **선택 항목으로 유지**(2026-09-15 결정). 제출·시연 기본 모드는 템플릿 제공자(`provider: template`)이며 판정·검증은 LLM 과 무관하다. 키를 넣으면(`ANTHROPIC_API_KEY`) 같은 화면이 `claude-opus-5` 설명으로 바뀌고, 혜택 설명(/recommend)에는 인용 검증기가 동일하게 적용된다. 채팅(/chat)은 인용 검증기 대신 '채팅 답변은 자격 판정이 아닙니다' 표기(eligibilitySource: rule-engine)와 부적격 제도 긍정 답변 교체·정정 장치로 다룬다(F22). 실제 키 경로는 가짜 클라이언트 테스트로만 확인했다.
- 고령자 사용성 평가 미실시. 카메라 QR 스캔 미검증(6자리 코드로 대체).
- 개발 서버 주의: 같은 앱 디렉터리에 `next dev` 두 개를 띄우거나 dev 중 `next build` 를 실행하면 `.next` 가 깨져 500 이 난다 → 해당 앱 dev 서버만 재시작.
